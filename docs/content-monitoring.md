# Content-copy monitoring (internal — do not publish)

Canary phrases placed in live body copy so copies can be found with Google Alerts and Copyscape.

| Phrase | Where it appears |
|---|---|
| "Mawkish Seam Check" | Home (How we work), Services hero |
| "One Name Rule" | Home (The engagement), Services hero |
| "Cabinet-Back Standard" | About (Our Culture & Principles) |
| "Whoever does the work, Mawkish checks it, owns it and answers for it" | Home |
| "Our partners deliver the technology. Our loyalty stays with you." | deck / reuse in future pages |

## Routine
- Google Alerts (google.com/alerts): one alert per phrase in quotes, e.g.
  `"Seam Check" "Mawkish" -site:mawkishtechnologies.com`; also alert on the bare coined terms
  `"One Name Rule" enterprise`, `"Cabinet-Back Standard"`.
- Every 3–4 months: run Home, About, Services and top service pages through Copyscape; run key graphics through Google Lens / TinEye.
- Log each finding (URL, date, screenshot, action taken) below.

## Rules
- Keep the exact spelling and capitalisation of each term wherever it is reused.
- Do not list these phrases on the public /copyright page.
- Canaries must carry no new factual claims (see USAGE RULES in the company profile).
